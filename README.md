#  LightHouse17 – Career Guidance Platform

LightHouse17 is a responsive career guidance web platform built using HTML, CSS, and JavaScript.  
It helps students and graduates explore career paths, understand skill requirements, and take actionable steps toward their goals.

This project focuses on practical career discovery through an interactive quiz, curated career paths, skill recommendations, and professional services like resume review and career counseling.



##  Features

###  Career Interest Quiz
- Interactive multi-step quiz
- Dynamic result calculation
- Personalized career suggestions
- Progress tracking

###  Career Path Explorer
- Filter by category (Tech, Creative, Business)
- Growth insights and salary expectations
- Skills required for each role

###  Skill Development
- Recommended courses
- Duration and learning level
- Beginner to intermediate roadmap

###  Jobs & Internships
- Entry-level roles
- Internship opportunities
- Search and filter functionality

###  Professional Services
- Resume Review
- Career Strategy Session
- Mock Interview
- Quick Career Consultation
- Booking modal system

###  Clean UI & UX
- Responsive design
- Modern but minimal styling
- Smooth interaction flow
- Structured layout


##  Tech Stack

- HTML5
- CSS3 (Custom styling, no frameworks)
- Vanilla JavaScript (ES6)
- Responsive Design Principles

No external UI frameworks were used.  
The project focuses on solid fundamentals and clean structure.
